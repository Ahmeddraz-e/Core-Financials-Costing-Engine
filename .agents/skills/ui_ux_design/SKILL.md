# UI/UX Expert Design Guidelines

This skill extends the agent's capabilities with advanced design principles for creating modern, stunning, and highly usable web interfaces.

## 1. Visual Hierarchy & Spacing
- **Grid Layouts**: Use CSS Grid and Flexbox for responsive, adaptive structures.
- **Spacing Scale**: Implement a strict 4px/8px spacing system (`gap-4`, `p-6`, `my-8`) to maintain visual rhythm.
- **Contrast**: Maintain a contrast ratio of at least 4.5:1 for text. Highlight important metrics with distinct backgrounds.

## 2. Color Palettes & Themes
- **Sleek Dark Mode**: Deep slate background (`#0b0f19`), translucent white borders (`rgba(255, 255, 255, 0.05)`), neon violet/cyan gradients.
- **Royal Enterprise**: Clean white/light gray background, dark blue (`#1e3a8a`) for structure, and emerald (`#10b981`) for positive indicators.
- **Neo-Brutalism**: Flat pastel fills, thick black borders (`2px solid #000`), aggressive shadows, and bold typography.

## 3. Micro-Animations & Interactivity
- Smooth transitions for hover effects: `transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);`.
- Scale on hover for interactive cards: `hover:-translate-y-1 hover:shadow-lg`.
- Use pulse indicators for active streams or alert centers.
